# Archived FlyVis / FAFB pipeline

This folder contains the **old** visual odometry stack based on:

- FlyWire / FAFB connectome (`fib25-fib19_v2.2.json`)
- FlyVis pretrained model `flow/0000/000`
- T4/T5 cardinal motion → ego-motion

The active project now uses **MaleCNS v1.0** via [`flybrain`](https://github.com/alextitonis/fly.ai) (PyPI: `flybrain`).

These files are kept for reference only — they are not imported by the live web app.
